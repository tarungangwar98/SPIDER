Assignment 5 – GitHub repository link

Push steps

On github.com click New repository → name it html-css-assignments → leave it empty (no README) → Create.
In your local project folder:
git remote add origin https://github.com/<your-username>/html-css-assignments.git
git branch -M main
git push -u origin main
Refresh the GitHub page and confirm all files and commits appear.
Optional: host it for free

Settings → Pages → Branch: main / root → Save. Your pages will be live at
https://<your-username>.github.io/html-css-assignments/.
